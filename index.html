Fast MP4 rendering

This uses the fast renderer included in this GitHub repository. It creates the full green-screen MP4 much faster than real time.

  1. Enter the final video duration and click Download render project.
  2. Download the renderer package and extract the ZIP.
  3. Install Node.js LTS once, then drag your downloaded render-project JSON onto render-project.bat.

The MP4 will be saved beside your JSON file. Add it above the match in CapCut and use Chroma Key on green.
